**Brick Brick** is a mobile puzzle game where you connect bricks to clear area and score points. It was created in one night to test my development speed (and to replicate a game my girlfriend plays that doesn't have ads.) The game was built in Unity and exported with WebGL so it can be played right in the browser below. Brick Brick is completely free and **[open source](https://github.com/bencatcraw/BrickBrick)** and is open to contributions!
